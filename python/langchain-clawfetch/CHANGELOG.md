# Changelog

## [0.2.0] - 2026-10-21

### Added
- `ClawFetchCompany` (`clawfetch_company`, $0.02): company profile from a domain via `POST /company`, sync and async. Included in `ClawFetchToolkit`.

### Changed
- Requires `clawfetch>=0.3.0`.

## [0.1.0] - 2026-10-18

### Added
- Initial release: `ClawFetchFetch`, `ClawFetchRender`, `ClawFetchExtract`, `ClawFetchResearch`, `ClawFetchParse`, `ClawFetchDomainsCheck`, `ClawFetchDomainsSuggest` tools (sync and async) and `ClawFetchToolkit`.
