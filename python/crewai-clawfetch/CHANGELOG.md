# Changelog

## [0.2.0] - 2026-10-21

### Added
- `ClawFetchCompanyTool` (`clawfetch_company`, $0.02): company profile from a domain via `POST /company`. Included in `clawfetch_tools()`.

### Changed
- Requires `clawfetch>=0.3.0`.

## [0.1.0] - 2026-10-18

### Added
- Initial release: `ClawFetchFetchTool`, `ClawFetchRenderTool`, `ClawFetchExtractTool`, `ClawFetchResearchTool`, `ClawFetchParseTool`, `ClawFetchDomainsCheckTool`, `ClawFetchDomainsSuggestTool` and the `clawfetch_tools()` helper.
